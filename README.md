# Ansible Learning Journey

## Project Overview

This repository documents my structured learning journey for Ansible, focusing on infrastructure automation, configuration management, and playbook development.

## Topics Covered

* Ansible Architecture
* Inventory Management
* YAML Fundamentals
* Playbooks
* Modules
* Variables
* Roles
* Configuration Management

## Repository Structure

* docs/ – Learning notes and concepts
* inventories/ – Sample inventory files
* playbooks/ – Practical automation examples
* reports/ – Progress reports
* screenshots/ – Environment setup and execution evidence
